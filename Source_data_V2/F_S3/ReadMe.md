Supplementary Figure S3. POPS performance across simulated outbreak datasets. Heatmaps show mean genomic coverage (left) and mean signal purity (right) across 26 simulated outbreak datasets at each POPS step: co-assembly, case recurrence, and control subtraction. Rows represent individual projects, grouped into respiratory pathogens and other pathogens. Values are means across simulated outbreaks within each project. Project labels include n1 and n3, denoting the number of simulated outbreaks with detectable pathogen-derived signal after co-assembly and after control subtraction, respectively. Asterisks indicate P<0.05 versus co-assembly (paired Wilcoxon signed-rank test).
